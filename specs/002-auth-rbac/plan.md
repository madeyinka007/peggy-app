# Implementation Plan: Authentication & RBAC (Slice 1)

**Branch**: `002-auth-rbac` | **Date**: 2026-10-25 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/002-auth-rbac/spec.md`

## Summary

Slice 1 delivers human authentication (Better Auth, verified in spike), RBAC (roles, permissions, role_permissions, user_roles), permission evaluator with owner-only condition, and API tokens (prefixed, hashed, Bearer auth). Most auth wiring patterns are verified in the spike (C-01…C-05). Remaining work: implement RBAC tables + evaluator, API token lifecycle, auth middleware, and wire everything into createApp.

## Technical Context

**Language/Version**: TypeScript 5.6 on Node.js 22 LTS
**Primary Dependencies**: better-auth 1.7, @better-auth/drizzle-adapter 1.7, drizzle-orm 0.45, pg 8, @neondatabase/serverless 0.10, zod 4
**Storage**: PostgreSQL 16 (Better Auth tables + RBAC tables + API tokens)
**Testing**: Vitest (unit for permission evaluator), integration tests against Postgres
**Target Platform**: AWS Lambda (API), local dev via Docker
**Project Type**: Monorepo — `packages/auth`, `packages/db`, `packages/http`, `apps/api`
**Performance Goals**: Sign-up/sign-in < 3s, permission eval < 10ms, token auth < 50ms overhead
**Constraints**: Lambda 29s timeout, auth rate limit 5/min/IP, cookie Secure/SameSite=Lax/HttpOnly
**Scale/Scope**: Single project (D2). Auth + RBAC only — no content, no media.

## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

- [x] **P-01 API never touches DB**: Auth/RBAC logic in `@peggy/auth` and `@peggy/db` services; controllers (routes) take services via DI.
- [x] **P-02 Domain never imports infra**: `@peggy/auth` depends on `@peggy/db` (port) and `better-auth`, not Express/Drizzle directly in domain logic.
- [x] **P-03 Core never imports Cloudinary SDK**: No media code in this slice.
- [x] **P-04 Core never imports Next.js**: Admin is separate; auth is API-only.
- [x] **DB-01/DB-02/DB-03**: RBAC tables are relational system metadata (migrated). No polymorphic FKs. No in-request DDL. Better Auth tables generated by CLI.
- [x] **Auth Port**: Better Auth behind `AuthPort`. Spike verified scrypt default, UUID interop, cookie cache JWE.
- [x] **D2 Single-project**: No tenant_id. No organization plugin.
- [x] **Security baseline**: Rate limit 5/min/IP on auth. CORS allowlist. Cookie flags. CSRF on mutations. Bearer for programmatic. Audit redaction.
- [x] **Quality gates**: Permission evaluator needs ≥80% branch coverage. Draft-leak fixture is hard CI gate.

No violations.
